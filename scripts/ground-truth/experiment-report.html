✦ I. Executive Summary

The Problem

Petrarca is a knowledge-tracking read-later app that models what the user knows at the granularity of individual claims. The existing claim-level matching system (MiniLM embeddings + NLI cross-encoder) was calibrated for detecting whether two atomic claims say the same thing. But when applied to the higher-level question — are two articles about the same thing? — it produced a 70% false positive rate. Claims share vocabulary across unrelated articles, especially within domains like Sicilian history.

This session built a complete article-level similarity pipeline from scratch: human calibration, embedding strategy experiments, 300-pair ground truth, threshold optimization, two-stage pipeline evaluation, corpus-wide analysis, and a synthetic regression benchmark.

Bottom line: A weighted combination of summary and claims embeddings (0.5 + 0.5) achieves 94% accuracy and ρ = 0.818 on 18 human-rated pairs. At scale, the simpler full-summary embedding achieves AUROC = 0.930 on 300 LLM-rated pairs, with a calibrated threshold at 0.55 yielding 91% precision at 75% recall. Embedding alone outperforms LLM-as-judge (89% vs 78% accuracy). The proposed document_similarity module for amygdala will make this reusable across projects.

✦ II. Calibration: Human Ground Truth

Building the Calibration Tool

Before measuring article similarity, we needed to fix the upstream data quality problem. The claim extraction pipeline was generating noisy, low-insight claims — product feature bullet points rather than genuine analytical insights. We built an interactive HTML calibration tool (claim-calibration.html) that lets a human rapidly classify claims and rate article pairs.

Calibration Method

18 article pairs were selected to span the full similarity range: near-duplicates (same article from different sources), thematically related (same topic, different angle), same domain (both history, unrelated subjects), and completely unrelated. Each pair was rated 0–2 by a human reviewer, where 0 = unrelated, 1 = thematically related, 2 = highly similar / near-duplicate.

This small but carefully stratified dataset provided the initial signal for evaluating embedding strategies before scaling up to 300 pairs with LLM ratings.

✦ III. Pipeline Prompt Overhaul

What Was Wrong

The original extraction prompt asked for "specific factual claims." This sounds precise but in practice produced product feature lists for tech articles and generic truisms for history articles. The word "specific" was interpreted as "concrete" rather than "analytically interesting."

Model Comparison

Three Gemini models were tested on the revised extraction prompt. The key metric was the rate of genuinely factual claims (containing verifiable, non-obvious information) versus generic/analytical claims.

Model Factual rate Insight rate Cost / article Latency
Gemini 3.1 Flash Lite 5% 91% ~$0.0003 ~1.2s
Gemini 2.5 Flash 12% 84% ~$0.001 ~2.1s
Gemini 2.5 Pro 18% 78% ~$0.008 ~4.5s

Counterintuitive result: the cheapest, fastest model produced the best claims. Larger models over-hedged and produced "analysis of analysis" rather than direct insights. Flash Lite’s constraint to short outputs forced it to be maximally informative.

The New Prompt Strategy

Key changes: (1) prioritize insights, patterns, and comparisons over bare facts; (2) require each claim to be something "a reader would find surprising or useful to remember"; (3) explicitly forbid generic product features, truisms, and restatements of the title.

✦ IV. Embedding Strategy Experiments

11 Strategies Tested

Each strategy embeds a different text representation of the article, then computes pairwise cosine similarity. All strategies use the same MiniLM-L6-v2 model (384 dimensions) via amygdala. The 18 human-rated pairs serve as ground truth.

Why Weighted Combination Wins

Summaries capture thematic overlap — the broad "aboutness" of an article. Claims capture specific informational content. These are complementary signals that occupy partially independent regions of embedding space. Averaging them preserves both geometry types, while concatenation (strategy 4) over-weights whichever text is longer.

Topic tags (strategy 6) are anti-correlated with human judgments — articles tagged "history" and "culture" appear maximally similar regardless of whether they discuss ancient Sicily or modern Norwegian poetry. This confirms that topic-level similarity is too coarse for article matching.

✦ VI. Threshold Calibration

Precision/Recall/F1 Sweep

With the positive class defined as LLM rating ≥ 2, we sweep the cosine threshold from 0.30 to 0.90 and measure classification performance.

Fig. 3 — Precision, recall, and F1 across cosine thresholds. The "knee" at 0.55 is where precision jumps to 91% while recall remains at 75%.

Each use case has a different tolerance for false positives. Feed ranking can afford more noise (the penalty is a slightly lower-ranked article); deduplication requires near-certainty (the penalty is hiding a unique article).

✦ VII. Two-Stage Pipeline

The Hypothesis

Embedding similarity is fast and cheap but misses nuanced similarity. An LLM can understand deep thematic connections but is expensive. The two-stage pipeline uses embeddings as a filter, then sends borderline pairs to an LLM judge for re-evaluation.

Results: Embedding Beats LLM

Method Accuracy Spearman ρ LLM calls
Embedding only (baseline) 88.9% 0.654 0
LLM only (baseline) 77.8% 0.586 18
Embed filter (0.35) + LLM 77.8% 0.641 15
Embed filter (0.40) + LLM 83.3% 0.769 11
Embed filter (0.45) + LLM 83.3% 0.734 8

Why LLM Under-performs

The LLM judge over-rates similarity for articles within the same domain. Two articles both about Sicilian history receive a high "similarity" score even when one discusses 12th-century Norman conquest and the other discusses 20th-century anti-Mafia trials. The LLM conflates topical proximity with informational overlap. Embeddings, by contrast, represent the actual content and naturally assign lower similarity to topically adjacent but informationally distinct articles.

Ensemble Methods

Ensemble Accuracy Spearman ρ
Weighted average (0.1 embed + 0.9 LLM) 88.9% 0.695
Max(embed, LLM) 83.3% 0.620
Ambiguous zone only (LLM for 0.35–0.65) 83.3% 0.632

No ensemble configuration outperforms the weighted embedding strategy (94.4% accuracy, ρ = 0.818). The LLM adds cost without improving accuracy. For production, embedding-only is the correct choice.

Cost analysis: Rating all 32,896 unique pairs in the 257-article corpus with the LLM would cost approximately $0.79. The cost is negligible, but accuracy is worse. The decision is quality-driven, not cost-driven.

The Sicily Effect

The corpus has a pronounced density asymmetry. Sicilian-history clusters have extremely high cohesion (0.75–0.88) because Wikipedia research articles on the same topic contain largely overlapping information from different angles. In contrast, AI/tech articles from Twitter bookmarks have lower cohesion (0.57–0.74) because they cover genuinely different topics under a broad "AI" umbrella.

✦ X. Amygdala Module Design

Proposed: document_similarity.py

The experiments in this session validate a clear pattern: embed document text with MiniLM, compute pairwise cosine, optionally re-rank with an LLM. This pattern is useful beyond Petrarca — any project with a document corpus (articles, learning materials, book chapters) could benefit.

Core API

def find_similar_documents(
    documents: list[Document],
    *,
    text_field: str = "summary",
    threshold: float = 0.40,
    llm_rerank: bool = False,
    llm_threshold: float = 0.50,
    max_pairs: int | None = None,
) -> list[SimilarityPair]

The module sits between cluster.py (raw pairwise cosine) and project-specific code (which currently orchestrates embedding, similarity, and LLM refinement). It encapsulates the two-stage pipeline pattern validated in this session.

Three Cross-Project Applications

Project Use case Unit
Petrarca Article deduplication, feed ranking, briefing cards Article summaries
Alif Sentence deduplication in generated practice content Arabic sentences
Hamarquizen Question overlap detection as content scales Quiz questions (Norwegian)

Auto-Research Patterns

The calibration workflow from this session follows the "autoresearch" pattern pioneered by Karpathy: define an immutable evaluation harness, let an agent modify the approach, measure against a fixed metric. The synthetic benchmark (50 pairs, ρ = 0.895) serves as the regression test for future threshold or embedding changes. The 300-pair LLM-rated dataset provides the production calibration target. Both are committed to the repository for continuous re-evaluation.

Key Decisions

  1. Production embedding: full_summary (simpler, validated at scale with AUROC = 0.930)
  2. Best experimental strategy: weighted 0.5 summary + 0.5 claims (94.4% accuracy, ρ = 0.818 — pending deployment decision)
  3. No LLM in production pipeline: embedding alone outperforms LLM judge
  4. General threshold: 0.55 cosine (91% precision, 75% recall)
  5. Dedup threshold: 0.64 cosine (96% precision, 73% recall)
  6. Regression test: synthetic benchmark with ρ = 0.895 committed for future validation
